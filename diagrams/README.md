# Diagrams

Editable draw.io sources live in `src/`, named `NN-topic.drawio`, where `NN` is the session number
used in `docs/` (e.g. `01-governance-architecture.drawio`).

PNGs in `src/export/` are generated by the `drawio-export` workflow on every push that changes a
`.drawio` file. Don't edit or export them by hand.
